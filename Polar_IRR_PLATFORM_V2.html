SIG Annotation Guidelines

Reference guide for identifying bad Polar HR signal. Follow the decision tree and use the category options when annotating.

Patterns to Flag

1. Flatline / Lockout

HR stays constant (e.g. 80 BPM) for an extended period while WHOOP shows normal variation. Often happens at session start when the strap hasn't locked onto the heartbeat yet.

2. Jump(s)

Abrupt HR changes — sudden jumps up or down that don't match WHOOP. Can be a single spike or multiple sequential jumps. Often appears as a "staircase" pattern.

3. Noisy Polar / Spikes

High-frequency noise, erratic spikes, or jittery signal. The trace looks "fuzzy" compared to WHOOP's smooth line. Individual spikes to extreme values (>220 or <30 BPM) also fall here.

4. Large Mismatch with WHOOP

Polar and WHOOP traces diverge significantly but neither shows obvious artifacts. The signals tell different stories — flag if the difference is sustained and Polar is the outlier.

5. Impossible Value

HR reading below 30 BPM or above 220 BPM, which are physiologically impossible in the study context.

Decision Tree

1See something weird in Polar? Check if WHOOP sensors show the same thing.
2Both devices agree? → Likely real physiology. Don't trim.
3Only Polar affected? → Bad signal. Trim it.
4Ambiguous? Check context: activity type, signal shape, motion. If in doubt, trim conservatively (mark it).

General Rules

  • Minimum duration: Flag regions ≥5-10 seconds. Brief 1-2s blips can be ignored.
  • Merge nearby regions: If gaps between bad segments are <30 seconds, merge into one trim.
  • Session start: Always check the first 30-60 seconds — flatline/lockout is common here.
  • Be conservative: When in doubt, flag it. It's better to over-flag than to miss bad data.
  • Impossible values: Any reading <30 or >220 BPM should always be flagged.
  • Data gaps: If Polar signal disappears entirely (no data points), flag the gap.
